# Практическая работа: Командный проект в Git

## Описание проекта
Данный репозиторий создан для выполнения практической работы по командной разработке с использованием системы контроля версий Git и платформы GitHub.

## Состав команды
* *Алина* — Управление репозиторием, работа с ветками и слиянием (Pull Requests)
* *Азиза* — Разработка и внесение изменений в функционал

## Используемые технологии и навыки
* Создание и управление ветками (Branch)
* Фиксация изменений (Commit)
* Проведение перекрестной проверки кода (Code Review)
* Слияние веток через Pull Request
